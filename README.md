# Nimrod Digitals Web

Public frontend for `nimroddigitals.com`, built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion. WordPress remains the headless content system.

## Start locally

1. Install Node.js 20+ and pnpm.
2. Run `pnpm install`.
3. Copy `.env.example` to `.env.local` and set the final WordPress CMS URL.
4. Run `pnpm dev`.

## WordPress contract

The initial integration uses the WordPress REST API at `/wp-json/wp/v2`. The CMS must expose public read access for published posts and media, enable HTTPS, and allow the production website origin where browser-side requests are later needed.

The `lib/wordpress.ts` client is fetched during the static production build. Keep CMS URLs and access credentials in environment variables; never commit secrets.
